# Target trial protocol: synthetic point-treatment demonstration

This design is fixed for the version-1 simulation before its new runs are
generated. It is not a registered clinical trial or a clinical effectiveness
claim. Previous single-seed prototype results were already known; this is not
retrospectively described as a blinded or preregistered analysis.

| Component | Specification and implementation boundary |
|---|---|
| Eligibility | Age 50–90 inclusive, >=365 days prior enrollment, no prior class use; flags are simulated, not derived from actual claims |
| Strategies | Initiate A versus initiate B at baseline; neither names a real treatment |
| Assignment | Observational; modeled using baseline age and binary comorbidity |
| Time zero | Relative day 0, when the simulated initiation occurs; eligibility and assignment aligned at baseline |
| Follow-up | Complete observation from days 1 through 180 for every generated person |
| Outcome | Binary adverse event with day in [1,180]; explicit NULL day means observed event-free follow-up |
| Contrast | Effect of baseline initiation; an ITT-style analogue in a setting without switching or adherence variation |
| Target | Eligible population generated by the specified mechanism |
| Estimand | E[Y(A)] - E[Y(B)], a marginal 180-day risk difference; not an odds ratio |
| Primary estimator | Logistic propensity model, stabilized IPTW, normalized weighted group risks (Hajek-style) |
| Uncertainty | 95% percentile patient-level pairs bootstrap; refit propensity, prevalence, and weights in every replicate |
| Diagnostics | Sequential cohort counts, group descriptives, fixed-denominator absolute SMDs, raw propensity overlap, pooled/group ESS and weight distribution |
| Numerical policy | Clip fitted probabilities to [0.01,0.99], count changed scores, report raw range; refuse rank deficiency, separation or nonconvergence |
| Sensitivity | No winsorization (primary), pooled 1st/99th and 5th/95th percentile weight caps; descriptive point estimates and diagnostics only |
| Simulation check | 100 consecutive seeds by default; compare crude and IPTW point errors against each cohort's known DGP benchmark; retain failures |

## Identification assumptions and what can be checked

Consistency, conditional exchangeability given age/comorbidity, positivity,
correct ascertainment, and correctly specified propensity probabilities are
assumptions of the causal interpretation. They are designed into this favorable
synthetic mechanism, not demonstrated for any real population. Numerical
diagnostics assess measured balance and empirical overlap; they cannot detect
all unmeasured confounding or prove structural positivity.

Independent people and complete follow-up are simulation assumptions. The
pipeline rejects incomplete follow-up instead of conditioning on post-treatment
survival/retention or counting unobserved events as absent. Missing baseline
values, invalid source codes, orphan IDs, and multiplied joins also stop the run.
There is no imputation model, censoring model, or cluster bootstrap.

## Analysis plan and acceptance checks

- Always export crude and adjusted estimates and all three weight policies;
  never choose a policy by significance or by the estimated effect's sign.
- Use 1,000 bootstrap resamples for the checked-in demonstration; 100 is a
  deliberately smaller smoke-test configuration, not the showcase analysis.
- A failed scheduled bootstrap fit prevents CI production; no silent retry,
  redraw, or subset selection. Repeated-simulation failures are explicitly recorded.
- Validate SQL against an independent boolean eligibility filter and boundary
  fixtures. Compare numeric calculations with hand-computed examples and the
  logistic score equations. Exercise invalid-input and failure paths.
- Save seeds, configuration, package versions, source/artifact hashes, source
  CSVs, cohort/weights, all bootstrap draws, and all simulation results.
- The simulation size (3,000 source people) is a computational demonstration
  choice, not a power-based clinical study-size justification. No confirmatory
  hypothesis test or family of p-values is reported.

## Not implemented

Time-varying exposures, adherence/per-protocol effects, survival curves,
censoring weights, competing risks, negative controls, unmeasured-confounding
analysis, true longitudinal new-user detection, real-data validation and
bootstrap CI-coverage evaluation remain outside version 1. These are not
claimed as completed work. See [methods](docs/METHODS.md).
